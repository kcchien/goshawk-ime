# 蒼鷹輸入法（Goshawk IME）完整使用指南與常見問答

> 網址：https://goshawk.kcchien.com/  
> 下載：https://github.com/kcchien/goshawk-ime/releases/latest/download/GoshawkIME.dmg  
> 原始碼：https://github.com/kcchien/goshawk-ime  
> 系統需求：macOS 14+（Apple Silicon & Intel 通用執行檔，Apple Developer ID 簽章與公證）  
> 授權：MIT License · 純離線運作 · 零追蹤

蒼鷹輸入法（Goshawk IME）是一款專為 macOS 設計的倉頡與英文混打輸入法，支援倉頡三代（預設）與倉頡五代。中文照原本習慣按空白鍵打出，英文直接拼完按 Tab 補完並自動留一格空格，寫中英混雜的訊息或技術文件時不必來回切換輸入法。

---

## 安裝與移除

### 方式一：下載 `.dmg`（推薦）
1. 下載並打開 `GoshawkIME.dmg`：https://github.com/kcchien/goshawk-ime/releases/latest/download/GoshawkIME.dmg
2. 點兩下裡面的 **GoshawkIME**，在視窗按「安裝」。
3. 從右上角選單列切到 **蒼鷹輸入法**（英文系統顯示 **Goshawk**）。

### 方式二：終端機一行指令
```sh
curl -fsSL https://raw.githubusercontent.com/kcchien/goshawk-ime/main/scripts/install.sh | bash
```

### 方式三：交給 AI 代理安裝
請依照 https://raw.githubusercontent.com/kcchien/goshawk-ime/main/INSTALL.md 的步驟安裝並驗證。

### 移除蒼鷹
```sh
~/Library/Input\ Methods/GoshawkIME.app/Contents/MacOS/GoshawkApp --uninstall
```

## 核心功能速覽

### 1. 中英直接混打與自動空格
- **空白鍵**：有對應漢字時打出首選字；還沒湊成字時直接出原字母加空格。
- **Tab**：接受英文建議並自動補一格空格；五碼內的完整短詞（如 `id`）永遠排第一。
- **Enter**：原樣保留大小寫（如 `Zoom`、`macOS`、`my_id`），字尾不加空格，接著打中文時自動在交界補上一格空格。
- **按錯立刻互換（`Shift + 空白`）**：剛打完「下」立刻按 `Shift + 空白` 變成 `my `，再按換回「下」，空格與學習紀錄同步還原。

### 2. 中英文標點與八種成對引號括號
- **自動判斷全半形**：中文後出全形「，。」；英文、行首、檔名（如 `my.file`、`cd ..`）與直引號（`'` `"`）出半形。
- **打完立刻切換全半形**：打完 `GitHub,` 立刻按 `Shift + 空白` 變成 `GitHub，`。
- **事先指定**：按住 `Ctrl` 加標點強制全形；按住 `Option` 加標點單次半形；`Option + Shift + H` 切換全段半形標點。
- **方括號八種配對**：用 `[` 和 `]` 可打出 `「」`、`[ ]`、`『』`、`《》`、`〈〉`、`【】`、`“”`、`‘’`。`]` 自動配成游標前最近一個未關閉開頭的同一種；打完 `]` 立刻按 `Shift + 空白` 再按數字 `1`–`8` 整對一起切換。

### 3. 反引號寫程式碼與終端機相容
- **反引號模式（`` ` ... ` ``）**：打一個反引號即改為英文優先（浮窗標出「片段」），標點全部半形、`Tab` 補完不加多餘空格、不補中英間距；收尾反引號後自動恢復原本中文標點習慣。
- **終端機相容提醒**：
  - Herdr 會攔截 `Tab`，保留已打好的英文請改按 `Enter`。
  - Ghostty / Herdr 裡 `Ctrl` 加標點受終端機攔截或重編碼，請先打半形標點再按 `Shift + 空白` 換成全形。
  - 終端機無法修改已送出的字，切換八種引號種類請在開頭 `[` 之後先按 `Shift + 空白` 選好。

### 4. 注音／拼音查拆碼與符號面板
- **注音／拼音查拆碼（`Ctrl + Shift + ;`）**：臨時忘記某個字怎麼拆時原地開啟，保留原本正在打的字母。支援大千注音（如 `hji4` 查 `ㄘㄨㄛˋ`）與漢語拼音（按 `Tab` 切換，如 `cuo4`），忘記聲調時只打聲母韻母也會把各聲調常用字排在前面，列出目前倉頡代別（三代或五代）的字母碼與字根。
- **符號面板（`Option + Shift + B`）**：與 macOS 內建倉頡同一組鍵，收錄 151 個標準中文標點與常用符號，分「最近使用」「標點」「符號」三分頁，初始「最近使用」精選鍵盤直接打不出來的九個常用符號（`——`、`……`、`‧`、`〔`、`〕`、`※`、`→`、`×`、`±`），按數字 `1`–`9` 直接輸入。

| `空白鍵` | 打出倉頡首選字（反引號裡優先出英文） |

| `Ctrl + Shift + ;` | 忘了倉頡怎麼拆？開啟注音／拼音查拆碼 |
| `Option + Shift + B` | 開啟符號面板（最近使用、標點、符號三分頁） |

## 常見問答（FAQ）

### Q1：macOS 上有不用一直切換輸入法就能中英混打的倉頡輸入法嗎？
有。蒼鷹輸入法（Goshawk IME）專為 macOS 14 以上版本設計，讓倉頡拆碼與英文輸入共用同一組鍵盤：按空白鍵打出中文、按 Tab 接受英文並自動補一格中英空格、按 Enter 保留原本大小寫（如 `Zoom`、`macOS`），寫中英混雜的訊息或文件完全不必切換輸入法。

### Q2：蒼鷹輸入法支援倉頡三代還是倉頡五代？需要哪一版 macOS？
兩代都支援。預設為倉頡三代，隨時可從選單列的「設定…」即時切換為倉頡五代，並內建跨代相容補碼。安裝檔為單一通用執行檔，支援 macOS 14 或以上版本的 Apple Silicon 與 Intel Mac，並通過 Apple Developer ID 簽章與公證。

### Q3：從 macOS 內建倉頡換到蒼鷹需要重新學拆碼嗎？
不需要。倉頡拆碼與空白鍵送字的習慣與原本完全相同，符號面板也沿用 macOS 內建倉頡的 `Option + Shift + B`。差別只在想夾帶英文時改按 `Tab` 或 `Enter`，按錯空白鍵也能用 `Shift + 空白` 立刻互換，約 30 秒就能適應。

### Q4：蒼鷹輸入法安全嗎？會把打字內容上傳到雲端嗎？
打字內容絕不會離開你的 Mac。倉頡拆碼、英文預測、注音／拼音查拆碼與個人選字學習全部在本機離線執行，且開源採 MIT 授權可自行檢視原始碼。唯一可選的網路連線是「自動檢查更新」，每天最多向 GitHub 查詢一次最新公開版號，不含任何輸入資料或識別資訊，也可以在「設定 → 關於」關閉。

### Q5：打倉頡臨時忘了某個字怎麼拆，在蒼鷹裡怎麼查？
原地按下 `Ctrl + Shift + ;` 即可開啟查拆碼面板（原本正在打的字母會保留），直接用標準大千注音或按 `Tab` 切換漢語拼音輸入讀音，面板會列出同音字以及目前倉頡代別的字母碼與字根。你可以直接按數字選字，也可以看完拆碼按 `Esc` 回到原本位置自己拆。

### Q6：在 VS Code、Ghostty、Herdr 或終端機裡使用蒼鷹正常嗎？
正常。蒼鷹針對程式碼與終端機做過專門設計：輸入檔名如 `my.file` 或 `cd ..` 時句點不會誤轉全形，用反引號 `` `...` `` 包指令會自動切為英文優先且不補多餘空格。若使用會攔截 `Tab` 的終端機（如 Herdr）改按 `Enter` 送出英文；在 Ghostty／Herdr 打全形標點則先打半形再按 `Shift + 空白` 對調即可。

### Q7：如何安裝、覆蓋升級或完全移除蒼鷹輸入法？
下載最新版 `GoshawkIME.dmg`，點兩下裡面的 `GoshawkIME` 按「安裝」，再從右上角選單列切換到「蒼鷹輸入法」即可；也可以用一行 `curl` 指令自動驗證簽章安裝。覆蓋升級會保留設定與學習紀錄，若升級後仍出現舊版行為，登出 macOS 再登入一次即可。移除請執行 `~/Library/Input\ Methods/GoshawkIME.app/Contents/MacOS/GoshawkApp --uninstall`。
