USER GUIDE

重點使用指南

點選下方主題快速查看，每次只呈現最相關的重點。

中英直接混打與自動空格

同一串字母，三個按鍵分流中英文。

  • 出中文

    有對應漢字時打首選字；還沒湊成字時直接出原字母加空格。

  • 夾帶英文詞（自動補空格）

    接受英文建議並補上一格空格，短詞如 id 永遠排第一。

  • 保留大小寫（不加尾空格）

    適合 Zoom、macOS、my_id；接著打中文時交界自動補一格。

  • 數字自動分辨選字或文字

    只有單一候選直接打數字（m120、k8s）；有重碼且顯示編號時按數字選字。

按錯不用重打：立刻互換

剛打完發現按錯空白鍵或 Tab，一組鍵立刻挽回。

  • 中英文立刻互換
    打完「下」按 變成 my ，再按換回「下」。
  • 空格與學習紀錄同步還原

    結果等同當初直接按另一個鍵，不會留下多餘空格或錯誤學習。

  • 終端機也能安全互換

    終端機裡會以底線暫留一個按鍵，打下一個字自動確認，絕不誤刪既有文字。

中英文標點自動判斷與切換

不用一直盯著全半形狀態，打錯立刻換最順手。

  • 依前字自動選全半形

    中文後出「，。」；英文、行首、檔名 my.file 與直引號 ' " 出半形。

  • 打完立刻換全半形
    GitHub, 後按 變成 GitHub，
  • 事先強制全形或半形

    按住 強制全形；按住 單次半形； 切換全段半形。

  • 彎引號看引號外面的中英文

    他說“AI” 後出「。」，He said “hello” 後出半形 .。

方括號打出八種常用引號與括號

結尾 自動配成最近一個開頭的同一種。

1 「」2 [ ]3 『』4 《》 5 〈〉6 【】7 “”8 ‘’
  • 打完整對一起換
    打完「明日」立刻換成 《明日》 （按 變【明日】）
  • 開頭先選種類（長句與終端機用）

    按 後先按 選開頭，打完按 自動配對。強制半形右括號按 。

用反引號寫指令與程式碼

寫文件夾雜變數與指令，不必手動切英文。

  • 打一個反引號立即英文優先

    浮窗標出 片段，按 留英文、標點全部半形、不補中英空格。

  • 補完英文不加多餘空格

    結尾反引號緊貼字尾，例如 `order_id`。

  • 收尾自動回中文習慣

    再打一個 結束，下一個標點沿用進入前的中文或英文習慣。

終端機相容速查

部分終端機會自行攔截特定組合鍵，照以下替代最順手。

  • Herdr 攔截 Tab

    想保留打好的英文，改按 Enter 送出。

  • Ghostty / Herdr 打全形標點

    先打半形標點，立刻按 Shift 加空白換成全形。

  • 終端機裡打指令或引號

    單字母誤出中文立刻互換，或先開 ；換引號種類請在開頭 先選。

忘了倉頡怎麼拆？用注音或拼音查字

就地查碼、看字根，不中斷原本打字進度。

  • 開啟查拆碼面板

    原本正在打的字母會完整留著，按 隨時退回。

  • 切換注音與漢語拼音

    支援標準大千注音（如 hji4 查 ㄘㄨㄛˋ）與拼音（cuo4）。

  • 列出三代／五代拆碼並直接選字

    同時顯示字母碼與字根（如「厝」mta 一廿日），按數字鍵直接輸入。

符號面板（151 個標準標點與符號）

和 macOS 內建倉頡同一組開關鍵，完全無縫銜接。

  • 開啟符號面板

    收錄「最近使用」「標點」「符號」三分頁，按 切換。

  • 數字直選，常用往前排

    按 1 至 9 直接輸入， 翻頁；選過的符號會排進最前面。

  • 標點含全形與半形原樣輸入

    依教育部《重訂標點符號手冊》排列，選半形不會被改回全形。

安裝、升級與移除

支援 macOS 14+（Apple Silicon 與 Intel），經 Apple 公證。

  • 三步安裝完成

    打開 GoshawkIME.dmg → 點兩下安裝 → 右上角選單列切到「蒼鷹輸入法」。

  • 找不到或升級異常

    在「系統設定 → 鍵盤 → 文字輸入 → 繁體中文」加入；覆蓋升級後若行為異常，登出再登入即可。

  • 一行指令乾淨移除

    ~/Library/Input\ Methods/GoshawkIME.app/Contents/MacOS/GoshawkApp --uninstall

設定與隱私承諾

打字內容絕不離開這台 Mac。

  • 倉頡代別、字級與速查即時調整

    預設倉頡三代，從選單列點「設定…」隨時切換五代、浮窗字體大小（小／標準／大）、查看快捷鍵速查或複製零隱私風險的診斷資訊。

  • 全本機運算與學習

    拆碼、英文建議、查拆碼與三類學習紀錄全部存本機，可單獨關閉或一鍵清除。

  • 唯一可關閉的更新檢查

    每天最多向 GitHub 查一次公開版號，不含任何輸入資料，可在設定「關於」關閉。

FAQ · 常見問答

常見問題與解答

針對倉頡使用者最常問的系統支援、學習門檻、隱私安全與終端機相容性，一次回答清楚。

macOS 上有不用一直切換輸入法就能中英混打的倉頡輸入法嗎？

有。蒼鷹輸入法（Goshawk IME）專為 macOS 14 以上版本設計，讓倉頡拆碼與英文共用同一組鍵盤：按 打中文、按 接英文並自動補空格、按 保留 Zoom、macOS 原樣大小寫，寫中英混雜的文字不必來回切換。

蒼鷹支援倉頡三代還是倉頡五代？需要哪一版 macOS？

兩代都支援。預設為倉頡三代，隨時可從選單列的「設定…」即時切換成倉頡五代。安裝檔為單一通用執行檔，支援 macOS 14 或以上版本的 Apple Silicon 與 Intel Mac，皆通過 Apple Developer ID 簽章與公證。

從 macOS 內建倉頡換到蒼鷹需要重新學拆碼嗎？

不需要。拆碼規則與按空白鍵送字的習慣和原本完全相同，符號面板也沿用內建倉頡的 。差別只在夾帶英文改按 或 ，按錯也能立刻用 互換，約 30 秒就能適應。

蒼鷹輸入法安全嗎？會把打字內容上傳到雲端嗎？

打字內容絕不會離開你的 Mac。拆碼、英文預測、注音／拼音查拆碼與個人選字學習全部在本機離線運作，且採 MIT 開源授權。唯一可選的網路連線是「自動檢查更新」，每天最多向 GitHub 查詢一次最新公開版號，不含任何輸入資料或識別資訊，並可在「設定 → 關於」關閉。

打倉頡臨時忘了某個字怎麼拆，在蒼鷹裡怎麼查？

原地按下 即可開啟查拆碼面板（原本正在打的字母會完整保留），直接用標準大千注音或按 切換漢語拼音輸入讀音，面板會列出同音字與目前代別的字母碼和字根，可直接選字或看完拆碼按 回到原本位置。

在 VS Code、Ghostty、Herdr 或終端機裡使用蒼鷹正常嗎？

正常。輸入檔名如 my.file 或 cd .. 時句點不會誤轉全形，反引號 裡會自動改為英文優先且不補多餘空格。若使用會攔截 Tab 的終端機（如 Herdr）改按 送出英文；在 Ghostty 或 Herdr 打全形標點則先打半形再按 切換即可。

如何安裝、覆蓋升級或完全移除蒼鷹輸入法？

下載最新版 GoshawkIME.dmg，點兩下裡面的 GoshawkIME 按「安裝」，再從右上角選單列切換到「蒼鷹輸入法」即可；也可以執行一行終端機指令自動驗證簽章安裝。覆蓋升級會保留所有設定與學習紀錄，若升級後仍看到舊版行為，登出 macOS 再重新登入即可。移除請執行 ~/Library/Input\ Methods/GoshawkIME.app/Contents/MacOS/GoshawkApp --uninstall。
